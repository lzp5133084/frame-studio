# 帧界 FrameStudio · 使用说明

> 适用版本：v0.1.4
> 提示：界面中专业词语（如"画质等级""帧率"）右上角有蓝色 **?** 图标，点击可看大白话解释。

## 一、启动

双击 `run.bat`。首次运行前请确认：
1. 已安装 Python 3.10+（命令行执行 `py --version` 能显示版本号）
2. 已执行 `py -m pip install -r requirements.txt`
3. `tools/ffmpeg/bin/` 下存在 `ffmpeg.exe`（缺失则运行 `scripts\download_ffmpeg.ps1`）

## 二、抽帧提取

将视频拆解为逐帧图片，供后续单帧处理 / 补帧 / 擦除使用。

1. 左侧导航点 **抽帧提取**
2. **视频文件**：浏览选择源视频，软件自动显示时长 / 分辨率 / 帧率 / 总帧数 / 编码 / 体积
3. **抽取参数**：
   - `全部帧`：逐帧拆解（90 帧视频 → 90 张图）
   - `按帧率抽取`：如设 5 fps，每秒只取 5 帧（减帧采样）
   - `按间隔抽取`：如设 2 秒/帧，每 2 秒取 1 帧
   - `按动态程度`：**剔除静止画面，只保留关键帧（录屏演示专用）**。静止讲解自动剔除，鼠标移动 / 翻页 / 滚动等关键操作自动保留；灵敏度滑杆 0~100：越高则渐变等轻微变化也保留，日常建议 60~90。该模式产出帧数取决于画面内容，进度条显示为忙碌态属正常
   - 格式：`PNG` 无损（推荐做中间帧）、`JPG` 体积小
4. **输出目录**：不填则默认 `workspace/frames_<视频名>/`
5. 点 **开始抽帧**，进度条实时显示；产出文件命名 `f_000001.png` 起
6. 点 **查看帧** 浏览抽出的帧：点击图片放大/还原（放大后可拖动滚动条看细节），← → 切换前后帧，Home/End 跳首尾，ESC 退出

## 三、帧序列合成

将帧序列合成为 MP4 视频 / GIF 动图 / PPT 幻灯片。

1. 左侧导航点 **帧序列合成**
2. **帧目录**：选择帧图片所在目录，自动识别命名模式（如 `f_%06d.png`）与帧数
3. **输出格式**：
   - `MP4 视频`：通用播放，可调 帧率 / 画质等级 CRF / 编码速度 / 分辨率
   - `GIF 动图`：网页、聊天分享用；可调帧率与 GIF 宽度（越小文件越小），自动生成最优调色板
   - `PPT 幻灯片`：每帧一页，适合步骤拆解汇报；配合「按动态程度」抽帧效果最佳（关键步骤一页一张）
4. **输出文件**：默认 `<帧目录>_out.<格式后缀>`，切换格式时自动改后缀
5. 点 **开始合成**（GIF/PPT 按钮文字随格式变化）

## 四、设置

| 项 | 说明 |
|---|---|
| 媒体引擎 FFmpeg | 留空使用内置版；也可指向自装版本 |
| 默认输出 | 全局输出根目录，默认 `workspace/` |
| AI 推理模式 | `混合`（推荐）/ `本地`（需 N 卡）/ `云端服务`（火山引擎）—— v0.2 起生效 |
| 火山密钥 ARK Key | 火山引擎 API 访问钥匙，云端模式必填 |

## 五、常见问题

**Q：提示"未找到 ffmpeg"？**
A：运行 `powershell -ExecutionPolicy Bypass -File scripts\download_ffmpeg.ps1` 自动下载内置版。

**Q：抽出的帧数比预期少？**
A：部分视频流元数据中的总帧数不准，属正常现象，以实际产出为准。

**Q：合成失败退出码非 0？**
A：检查帧序列是否有断号（如缺 `f_000005.png`），ffmpeg 遇断号即停。后续 v0.2 的"帧缺口自动补全"会解决此问题。
