## v0.1.0 — 2026-10-23

### 需求背景（交流决策摘要）

1. 用户要做"处理视频的工具平台"，初议方向为通用再编辑平台；曾调研 OpenCut / LosslessCut / Shotcut / OpenShot 等开源项目。
2. 用户澄清真实工作流：**抽帧 → 单帧处理 → 帧数自动补全 → 批量字幕/文字/水印 → 自定义擦除（物品/人）→ 缺失处自动补全/替换**。判定为"帧级 AI 处理流水线"而非时间线剪辑，放弃 OpenCut 方案，改用 **Python + PySide6 + FFmpeg + AI 模型**自研。
3. 三项关键决策：
   - 历史抽帧/单帧工具代码：由 AI 自主处置（当前为空仓库，从零搭建并保留同名功能模块）
   - AI 推理：**本地 + 云端可切换**（设置页可选 本地/云端/混合）
   - 擦除交互：**多维度自定义**（涂抹框选 + SAM 点选 + 文本描述识别，v0.4 实现）
4. 形态：先做 Windows 桌面应用，后续迭代 Web 版。

### 本版实现

- 项目骨架：`app/{core, modules, ui}` 三层 + `tools/ffmpeg` 内置引擎 + `workspace` 工作目录
- **抽帧提取**：全帧 / 按帧率 / 按间隔三模式，PNG/JPG 输出，ffprobe 自动显示视频信息，实时进度条，可取消
- **视频合成**：自动识别帧序列命名模式与帧数，CRF / 编码预设 / 分辨率可调，H.264 + yuv420p 高兼容输出
- **设置页**：FFmpeg 路径、默认输出、AI 推理模式（本地/云端/混合）、火山引擎 ARK Key 持久化（QSettings）
- **占位页**：智能补帧（v0.2）/ 字幕水印（v0.3）/ 智能擦除（v0.4）功能规划展示
- 2027 商用级深色主题：近黑底 + 电光蓝紫渐变强调 + 圆角卡片 + 左侧导航
- 内置 FFmpeg 9.0.2（`tools/ffmpeg`，提供 `scripts/download_ffmpeg.ps1` 自动下载，不入 git 库）

### 验证

- offscreen 实例化全部 6 个页面通过
- 端到端测试：3 秒 90 帧测试视频 → 抽出 90 PNG → 识别 `f_%06d.png` → 合成 MP4，全部通过
